# Crimson

A dark crimson theme for **Linux Mint Cinnamon**: black panel with burgundy details, dark windows with red controls, red-tinted Papirus icons, translucent terminal and file manager, and a matching bash prompt.

## Palette

| Name | Hex |
|---|---|
| Preto | `#0B0B0D` |
| Bordô | `#64101F` |
| Crimson | `#B51F3B` |
| Marfim | `#E8E2E3` |

## What's included

- **Crimson** GTK 3/4 + Cinnamon theme (based on Mint-Y-Dark-Red)
- **Papirus-Crimson** icons: red folders and app icons recolored to the palette
- Elegant 45px panel with rounded, translucent applets
- Nemo file manager at 25% transparency (desktop untouched)
- GNOME Terminal colors, 25% transparency and a crimson prompt
- Prism Launcher theme

## Install

```bash
git clone https://github.com/PRMEidiot/crimson-theme.git
cd crimson-theme
./install.sh
```

Drop a `wallpaper.jpg` in the folder before running to set it as the background. Your previous settings are saved to `~/.crimson-backup.txt`.
